# Dedicated Servers

---
A **dedicated server** is a computer or server that is used specifically to host a multiplayer game for other players. Instead of requiring one player's gaming computer to host the game while they are playing, the dedicated server operates separately and allows multiple players to connect to the same game session. This can provide a central location for storing the game world, processing multiplayer information, and managing the players connected to the server. Dedicated servers are commonly used in [[Multiplayer Games]] where players need access to a persistent or centrally managed game. They can also be useful when [[Playing games with friends main pages|playing games with friends]] because the person hosting the server does not always need to be actively playing for other players to connect.

---
## Steam and Dedicated Servers

[[Steam]] has supported dedicated servers for many PC games. Some games provide a separate **Dedicated Server** tool that can be installed through Steam, while others use **SteamCMD**, Valve's command-line version of the Steam client, to download and update server software. Steam also provides a **Game Servers** browser that can display servers for supported games. Players can use the browser to locate servers and can add specific servers to their favorites using the server's address. Some games also provide their own integrated server browser that displays available dedicated servers directly inside the game. ([[References]]) The exact process depends on the individual game. For example, some games automatically list public dedicated servers, while others allow players to directly connect using the server's IP address.

---
## Integrated Server Browsing

An **integrated server browser** makes dedicated servers easier for players to discover. Instead of requiring players to manually enter an IP address, a game can display a list of available servers and information about them. Depending on the game, the server browser may show the server's name, current number of players, maximum player count, game mode, map, and connection information like ping. Players can then choose a server from the list and connect to it. Steam's Game Servers system can also be used with supported games to locate and favorite servers. Steam Community documentation demonstrates that players can open Steam's **Game Servers** interface and add a dedicated server using its public IP address and query port. ([[References]])

## Hosting a Dedicated Server

Hosting a dedicated server requires both [[Software Main Pages|software]] and [[Hardware Main Page|hardware]]. The computer running the server needs enough processing power, memory, storage, and network capacity for the game and the number of connected players. Some dedicated server programs can run without displaying the game's normal graphics. This means that a server may not require the same level of graphics hardware as the gaming computers connected to it. Instead, resources such as the [[CPU]], [[RAM]], storage, and network connection can become more important. Server administrators may also be able to configure settings such as the server name, player limit, passwords, maps, game modes, and permissions. Some games even allow [[Game Mods]] to be installed on dedicated servers to provide custom gameplay.

---
## Dedicated Servers and Playing With Friends

Dedicated servers can provide players with another method of [[Playing games with friends main page|playing games with friends]]. A group can operate a private server and use a password to limit access, or the server can be made public so other players can discover and join it. This differs from [[Peer-to-Peer Multiplayer]], where one of the players' computers may act as the host. With a dedicated server, the server exists separately from the individual players connecting to it. Dedicated servers can also support communities that regularly play the same game. Because the server can remain available independently of a particular player's gaming session, players may be able to leave and reconnect later depending on how the game and server are designed.
