# LAN Gaming
---
LAN or (Local Area Network) gaming provides another method of [[Playing games with friends main page|playing games with friends]]. Because everyone is physically located in the same area, players can communicate directly while still having their own computer and controls. **Minecraft: Java Edition** is a good example of a game that supports LAN gaming. A player can open a single-player Minecraft world to their local network using the **Open to LAN** option. Other players connected to the same local network can then join the world through Minecraft's multiplayer menu. This allows a group of players to play together without setting up a permanent [[Dedicated Servers|dedicated server]]. ([[References]])
Minecraft can also be played using a dedicated server. Instead of requiring the player who owns the world to open their game to LAN each time, Minecraft provides dedicated server software that can host a world separately. This demonstrates the difference between a temporary LAN-hosted game and a [[Dedicated Servers|dedicated server]]. LAN parties combine several areas of PC gaming, including [[Hardware Main Page|computer hardware]], networking, [[Software Main Pages|software]], [[Peripheral devices main pages|Peripheral devices]], and [[Multiplayer Games|multiplayer gaming]].
