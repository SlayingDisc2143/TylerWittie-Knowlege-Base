# Peer-to-Peer Multiplayer
---
**Peer-to-peer multiplayer (P2P)** is a type of multiplayer networking where players' computers communicate directly with each other rather than relying entirely on a separate [[Dedicated Servers|dedicated server]]. Similar to a [[LAN Gaming|LAN]] it uses the broader WAN to connect different PCs. In many P2P games, one player's computer acts as the **host** while the other players connect to it. P2P can make it easier for smaller groups to play together because a separate server does not always need to be maintained. However, the connection quality of the host can affect the other players. If the host leaves, the game may need to select a new host or end the session. P2P is one of several ways [[Multiplayer Games]] can connect players, alongside [[Dedicated Servers]] and [[LAN Gaming]].
