#### CPU 
---
The CPU, or Central Processing Unit, is responsible for processing instructions and performing calculations for the computer. A more powerful CPU can improve performance in games, multitasking, programming, video editing, and other demanding applications. Important things to consider include the number of cores, clock speed, power requirements, and compatibility with the motherboard. It is also important to consider the type of CPU needs to correlate to the Motherboards model, as some motherboards require different CPUs for compatibility. The CPU is also required to be cooled while running, as it heats up significantly while electricity pulses through each transistor within the contents of the CPU.
