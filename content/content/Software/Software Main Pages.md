## Software

Software is a collection of programs and instructions that allow a computer to perform different tasks. While [[Hardware Main Page|Hardware]] represents the physical components of a computer, software provides the instructions that allow those components to be used. For PC gaming, software is responsible for everything from operating the computer to launching and running games.

### Common Types of Software

- [[Discord]] – The primary software responsible for managing a computer's hardware, applications, files, and other resources.

- [[Device Drivers]] – Software that allows the operating system to communicate with hardware such as graphics cards, audio devices, and [[Peripheral devices main pages|Peripheral devices]].

- [[Game Launchers]] – Applications used to purchase, install, update, organize, and launch video games.

- [[Game Mods]] – User-created or community-created modifications that change or add content to existing games.

- [[Anti-Cheat Software]] – Software designed to detect or prevent players from using unauthorized programs to gain an advantage in multiplayer games.

---
### Software and PC Gaming

Software plays an important role in determining how games interact with a computer. The [[Discord|operating system]] provides the environment where applications and games can run, while [[Device Drivers|device drivers]] allow games to properly communicate with the computer's hardware. Players also commonly interact with [[Game Launchers]] to install and manage their games. Additional software such as [[Game Mods|game mods]] can change the experience of supported games, while [[Anti-Cheat Software|anti-cheat software]] is commonly used in competitive multiplayer games to help maintain fair gameplay.
