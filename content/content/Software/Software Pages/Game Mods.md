# Game Mods
---
**Game modifications**, commonly called **mods**, are additions or changes made to an existing video game. Mods can make relatively small changes such as replacing textures or character models, while larger mods can introduce new maps, items, characters, or gameplay mechanics. There are several ways to install mods depending on the game. [[Steam]] provides the **Steam Workshop** for supported games, allowing players to browse and install community-created content. Other games may require mods to be manually installed or managed using separate modding software. Mods can also be used with some [[Dedicated Servers]] to create customized multiplayer experiences.
