# Anti-Cheat Software
---
**Anti-cheat software** is designed to detect or prevent players from using unauthorized programs or modifications to gain an unfair advantage in [[Multiplayer Games]]. Anti-cheat systems are especially common in competitive games where cheating can negatively affect other players. Different games use different anti-cheat systems. Examples include **Valve Anti-Cheat (VAC)** in games available through [[Steam]] and **Easy Anti-Cheat**, which is used by a variety of PC games. Anti-cheat software operates alongside the game and other [[Software Main Pages|software]] to help maintain fair multiplayer matches.
