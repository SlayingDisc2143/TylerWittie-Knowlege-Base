# Game Launchers
---
**Game launchers** are programs used to purchase, download, install, update, and launch video games. Instead of manually managing every game installed on a computer, a launcher provides a central location where players can access their game library. There are several major [[Game Launcher Homepages|game launchers]] available for PC. Examples include [[Steam]], [[Epic Games]], the [[EA Game Launcher|EA app]], and the [[Xbox App]]. Launchers can also provide additional features such as automatic updates, cloud saves, friends lists, achievements, and access to [[Multiplayer Games|multiplayer games]].
